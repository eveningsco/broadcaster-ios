# Which screenshot scenes a changed file can affect. Used by
# `scripts/ci-screenshots.py --scenes auto` (the default) to capture only the
# scenes a branch's changes touch since its last full screenshot run.
#
#   <glob>  <scene> [<scene> ...]
#
# Globs are matched against repo-relative paths with fnmatch (`*` also matches
# `/`). The FIRST matching line wins, so put specific paths above broad ones.
#   ALL   every still scene (shared look: type, fonts, assets, app shell)
#   NONE  no visual effect (networking, recording, upload)
# A changed file that matches no line counts as ALL, so a new view file is
# screenshotted everywhere until someone maps it here.
#
# `-demo` recordings (edit-demo, track-demo, page-demo) are never chosen
# automatically; they cost ~30-60 s each. Ask for them with --scenes.
